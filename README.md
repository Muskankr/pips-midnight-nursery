
# Pip's Midnight Nursery 🌙

**A portfolio for a little dream engineer.**

Built for haX.baby's Baby's First Website hackathon — Track 1: Pip.

## The story behind the build

Pip is a curious, sleepy little skull-faced baby and Junior Dream Engineer at the Midnight Nursery. Pip creates lullabies, glowing nightlights, and safe routes through the night sky to help the neighborhood's little creatures find peaceful dreams.

I imagined Pip's portfolio as a tiny corner of the early internet: a dreamy digital nursery with retro labels, a starry palette, playful interactions, and a welcoming personality.

## Features

- Responsive portfolio layout for desktop and mobile
- Day/night theme toggle
- Interactive project cards with messages from Pip
- Web Audio API chimes with a visible sound toggle
- Hidden star-click Easter egg
- Illustrated, three-part origin story

## Tech stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Custom CSS animations
- Web Audio API

## Run locally

```bash
npm install
npm run dev
```
